使用说明

      
    

    

      
这个页面是什么

      
三模式复盘工作台：每天收盘后更新一次，用来判断情绪周期、挑候选、定买卖点。

      
怎么用

      
    
        
  1. 点右上角「更新数据」（收盘后 15:00 之后跑最准），等 30~60 秒
    2. 
        
  2. 先看总览：情绪阶段、涨停家数、连板高度，判断今天该进攻还是防守
    3. 
        
  3. 再看模式一：连板晋级率（一进二、二进三…）和各层级名单
    4. 
        
  4. 模式二：3板+ 回调的票，横幅直接告诉你今天该不该做、有几只符合高胜率条件
    5. 
        
  5. 模式三：当日大阳线 + 低位温和放量的候选
    6. 
        
  6. 竞价：第二天 9:15–9:25 打开，自动判断锚定池超预期/不及预期，给开仓结论
    7. 
        
  7. 当日复盘：一句话结论 + 次日验证点，可导出成 Markdown
    8. 
      

      
数据从哪来

      
全部来自公开行情接口，由你的浏览器直接抓取并当场计算：腾讯的全市场报价和个股日K、东方财富的涨停/炸板/跌停池、新浪的行业分类。不需要服务器，不需要安装任何东西。

      
在别的电脑上怎么用

      
把这一个 HTML 文件复制过去（U盘、微信、网盘都行），双击用浏览器打开就能用，功能完全一样。数据会现抓，不存在"数据没带过去"的问题。

      
注意

      
    
        
  • 每次更新约 5~10MB 流量，建议在 WiFi 下点
    • 
        
  • 盘中数据是半根K线，模式三的"3天小阳"和模式二的"距顶天数"会偏，收盘后再跑
    • 
        
  • 模式三的历史形态需要累积 4 个交易日，每天点一次更新会自动累积
    • 
        
  • 点表格里任意一行可以看该股日线图（K线+均线+成交量+MACD），Esc 关闭
    • 
        
  • 本工具只做数据整理和统计，不构成投资建议，盈亏自负
